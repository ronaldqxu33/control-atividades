#  atividades RONALD

Um gerenciador de tarefas desenvolvido em Python com interface gráfica, utilizando Tkinter e banco de dados SQLite.

O objetivo do projeto é facilitar a organização de atividades, permitindo cadastrar, editar, concluir e excluir tarefas de forma simples e intuitiva.

## 🛠 Tecnologias utilizadas

- Python
- Tkinter
- SQLite
- PyCharm

##  Funcionalidades

- Cadastrar tarefas.
- Definir prioridade: alta, média ou baixa.
- Editar tarefas existentes.
- Marcar tarefas como concluídas.
- Excluir tarefas com confirmação.
- Armazenar informações em banco de dados SQLite.

##  Estrutura do projeto

```text
task-manager/
│
├── main.py
├── main_terminal.py
├── interface.py
├── tarefa.py
├── database.py
├── dados/
│   └── tarefas.db
└── README.md
```

## ▶Como executar

1. Instale o Python.
2. Clone este repositório.
3. Abra a pasta do projeto no PyCharm.
4. Execute o arquivo `interface.py`.
